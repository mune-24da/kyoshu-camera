# kyoshu-camera

ウェブカメラの映像から挙手を検出し、挙げた順に並べる試験用スクリプト。大喜利会の挙手順をボタンの代わりにカメラで取れるかを確かめるために作った。

ブラウザ版は https://mune-24da.github.io/kyoshu-camera/web/ で開ける(スマホ可)。

## 起動

`start.bat` をダブルクリックする。カメラ番号を変えるときは `start.bat --camera 1` のように渡す。

初回だけ環境を作る場合:

```
python -m venv .venv
.venv\Scripts\python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python -m pip install ultralytics opencv-python
```

## 判定のしかた

骨格推定(YOLO11n-pose)で鼻・両肩・肘・手首の位置を取り、左右それぞれの腕で次の3条件を見る。値はすべて肩幅を1とした長さ。

- 鼻: 手首が鼻より0.10以上上にある(顔に手を当てる・飲む動きを弾く)
- 腕: 手首が肘より0.15以上上にある(前腕が立っている)
- 肘: 肘が肩より0.02以上上にある(肘を下げたまま頭をかく動きを弾く)

どちらかの腕で3条件がそろった状態が0.6秒続いたら挙手、そろわない状態が0.6秒続いたら解除とする。左上に各条件の成否が○×で出る。基準は `--over` `--forearm` `--elbow` `--hold` で変えられる。

2026-09-24の録画(挙手8回、顔に手を当てる、頭をかく左右各1回、飲む動作)で確かめた結果、挙手8回はすべて検出し、顔に手を当てる・飲む・左手で頭をかく動きは弾いた。右手で頭をかく動きは挙手と区別できなかったので、誤検出は司会が取り消す運用で吸収する。

## キー操作

- `1`〜`9` その席を順番から取り消す。取り消された人は、一度手を下ろして挙げ直すまで並ばない
- `x` 最後に並んだ人を取り消す
- `r` 挙手の順番をリセットする
- `q` / `Esc` 終了

## 記録

`logs/` に毎フレームの左右の値・3条件の成否・挙手状態をCSVで残す。頭をかく・顔に触る動きと挙手を見分けるための候補の値(手首と鼻の横方向の距離、手首が鼻より上か、前腕が立っているか、肘の高さ)も一緒に残す。

映像は通常は保存しない。`start-record.bat` で起動したときだけ、カメラの生の映像を `logs/<日時>.mp4` に、各コマの時刻を `<日時>.times.txt` に保存する。保存した映像は `start.bat --video logs\<日時>.mp4` で読み直し、判定を作り直したときに同じ映像で比べられる。

## ブラウザ版(web/)

スマホや他人のPCでもインストールなしで動かすための版。判定の3条件・継続秒数・取り消しの扱いは Python 版と同じで、骨格推定だけ MediaPipe Pose Landmarker(Apache-2.0)に置き換えている。ライブラリとモデルは CDN から読むので、初回はネットにつながっている必要がある。

手元で開くときはこのフォルダで `python -m http.server 8896` を立て、`http://localhost:8896/web/` を開く。スマホのブラウザでカメラを使うには HTTPS のページが要る。

録画での確かめ方: 録画は mp4v 形式でブラウザが再生できないので、`ffmpeg -i logs\<日時>.mp4 -c:v libx264 -pix_fmt yuv420p -g 1 -r 10 logs\<日時>.h264.mp4` で変換し、`http://localhost:8896/web/?video=../logs/<日時>.h264.mp4&times=../logs/<日時>.times.txt` を開く。

2026-09-24の録画で比べた結果、挙手8回はすべて検出し、Python 版で拾ってしまった右手で頭をかく動きは弾いた。ただし MediaPipe は YOLO より肘を少し低く見るようで、肘を肩の高さぎりぎりまでしか上げない挙手では、肘の条件が途中で外れて挙手が一度途切れることがあった(同じ席は並び直さないので順番は変わらない)。

## 制限

- 席番号は画面の左から順に振っているだけ。人が動くと番号が入れ替わる
- 複数人での隠れや取り違えは未検証
